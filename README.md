## Design & Architecture
This portfolio is built with a focus on modern web aesthetics and performance. 
- **Dark-Mode Glassmorphism**: Features a deep space navy theme with vibrant purple, blue, and cyan gradient accents.
- **Interactive UI**: Project cards act as buttons that open animated glassmorphism modals with detailed descriptions.
- **Micro-interactions**: Includes floating background particles, animated stat counters, and a typewriter hero effect.
- **Lightweight**: Built entirely with pure **HTML, CSS, and Vanilla JavaScript**. No heavy external libraries or frameworks were used, ensuring fast load times.

## Built With
- **HTML5**: Semantic structure and accessibility (ARIA labels, keyboard navigation).
- **CSS3**: Custom properties (variables), Flexbox/Grid layouts, glassmorphism filters, and smooth keyframe animations.
- **JavaScript (Vanilla)**: DOM manipulation, Intersection Observers for scroll animations, and modal management.
